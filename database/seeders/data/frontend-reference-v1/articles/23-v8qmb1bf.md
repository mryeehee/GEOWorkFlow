在 GEOWorkFlow 中，**GEOWorkFlow URL 智能采集**是将网页转化为可管理知识资产的关键入口。它的核心作用是把外部网页批量转成结构化的知识库、关键词库和标题库素材，为后续 AI 生成与分发提供可直接引用的资源。

## GEOWorkFlow URL 智能采集是什么
GEOWorkFlow 是一套面向 GEO（面向 AI 搜索引擎的内容工程）的内容管理系统。它依靠素材库为 AI 模型提供可核验、可召回的背景信息。URL 智能采集通过自动抓取网页并解析入库，把一次性阅读内容转成系统中可复用的知识资产，从而补充知识库、关键词库和标题库的内容来源。根据当前资料，该功能属于“配置素材库”中的关键一环，是快速建设内容体系的基础操作。

## GEOWorkFlow 如何把网页转为知识库、关键词库和标题库
URL 智能采集通过结构化解析来生成三类核心资产：
- **知识库**：网页正文被提取、清洗并切片，用于 RAG（检索增强生成）召回；通过配置 Embedding 模型，文本片段转化为向量索引，供 AI 生成文章时调用相关真实资料。
- **关键词库**：系统可自动从网页中抽取关键词或短语，或由用户补充确认，用来指导内容生成方向并增强文章的相关性和搜索可见度。

## 实际操作中的使用步骤
GEOWorkFlow URL 智能采集的具体界面和操作按钮虽未在现有证据中详细列出，但依据系统的“配置素材库”指引，可完成以下流程：
1. 登录 GEOWorkFlow 后台并进入素材配置区。
2. 使用 URL 智能采集功能输入目标网页地址，一次可提交单个或多个 URL。
3. 选择采集目标，指定处理为知识库条目、关键词或标题库。

## 使用注意事项
- 网页内容需能被系统正常抓取和解析，动态渲染或需要登录的页面可能无法直接使用。
- 采集后的知识库条目将被切片，建议先选用真实、可验证的业务资料作为素材来源。
- 如需知识库支持 RAG 召回，必须在模型配置中提前添加 Embedding 模型并设置合适的切片策略。
- 该功能目前不自动处理图片与多媒体内容，相关图片资源需要单独在图片库中维护。

## 检查清单
- 已在后台“配置素材库”中看到采集入口或相关选项。
- 提交的网页 URL 可公开访问且无强制登录墙。
- 已为知识库配置有效的 Embedding 模型，以支持后续 RAG 生成。
- 采集完成后人工抽查知识库切片、关键词和标题质量。
根据当前资料，GEOWorkFlow URL 智能采集是“配置素材库”的能力延伸，具体操作路径和界面说明应以实际部署版本为准。
