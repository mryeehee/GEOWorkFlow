GEOWorkFlow 前台包含首页、分类页、文章页、关于页和归档页五种页型。v2.3.0 中 Enterprise Signature 21 主题覆盖全部页型，提供统一的 SEO metadata，确保标题、Open Graph 与结构化数据一致。页面由所选主题包模板驱动；后台站点设置可配置首页模块与样式，配置结果会同步到目标站点包，保持静态站点或远程分发时首页结构不变。

## 首页模块化配置
管理员在站点设置中启用、排列和定制首页功能模块，包括模块开闭、排版调整与样式定制，变更实时反映到前台渲染。卡片摘要会自动清洗 Markdown 符号，避免显示未解析格式。

## 分类与归档列表
分类页和归档页采用卡片式列表，展示标题、摘要和时间。摘要同样移除 Markdown 语法符号，以纯文本呈现，该清洗逻辑在主题层内置且可随主题扩展。页面 URL 由路由规则结合分类标识或归档参数自动生成：分类页以 `/category/{slug}` 访问，归档页按年份和月份自动聚合，无需手动配置。

## 文章详情与 SEO
文章详情页展示完整正文、封面图及结构化数据。所有主题共享一套 SEO head 逻辑，`title`、`description`、Open Graph 等在文章保存时自动生成，也可通过 SEO 设置面板手动覆盖。Enterprise Signature 21 主题还包含配套静态资源与增强可发现性的元信息。

## 主题定制与注意事项
主题视图位于 `resources/views/theme/<theme-id>`，静态资源位于 `public/themes/<theme-id>`，并包含模板、资源文件与主题配置，定义前台信息架构。后台支持主题预览与启用。使用仓库内置统一 `$geoflow` Skill 可将参考网址快速映射为 GEOWorkFlow 兼容主题包，输出 `tokens.json`、`mapping.json` 和模板规划，保证自定义主题自动继承页面架构并接入 SEO。更换主题后首页模块配置不丢失，但可能需微调布局。摘要清洗 Markdown 是主题层通用处理，不可单独关闭。所有主题共用同一套基础 SEO metadata。
