GEOWorkFlow 增长中心内置系统总览、单站内容运营、多站点分发与自助日志分析四个视图，集中呈现内容生产、分发质量、AI可见度与流量趋势。系统总览展示任务执行状态、分发状态与日志错误数量，用于每日快速巡检。单站内容运营显示发布趋势与内容分类分布，用于内容复盘。多站点分发列出各渠道成功/失败数量与最近错误详情，用于优先清理失败渠道。自助日志分析提供 AI 爬虫抓取记录与 Top 内容列表，用于 GEO 与 AI 搜索监控。以上视图均为只读面板，需使用者拥有“查看仪表盘”权限。

## 衡量内容生产力
每日登录后打开系统总览，确认内容生成任务无积压或失败，草稿及审核中的文章比例是否异常。周度或月度复盘时进入单站内容运营，观察发布趋势与分类分布；若某类知识库长期无产出，应调整知识库质量或提示词模板。结合人工发布工作台的执行统计（需管理员权限），查看外部平台完成率与延迟，间接衡量从知识库到最终发布的流水线效率。

## 分发与流量表现
多站点分发面板列出所有绑定站点和 HTTP API 渠道的最近分发记录，重点展示失败渠道和最后一次错误信息。若某站点连续分发失败，应先检查凭证或 API 可用性，再调整任务配置中的发布范围。自助日志分析可筛选主流 AI 爬虫的抓取行为，Top 内容排名反映被 AI 爬虫频繁请求的内容 URL，可作为 AI 搜索可见度代理指标。高排名页面通常意味着其结构与语义匹配更好。流量评估以 AI 爬虫抓取频次和 Top 内容覆盖率为主。

## 检查清单
- 系统总览中无持续性任务失败或日志错误
- 多站点分发面板中无新增失败渠道
- 自助日志分析显示主流 AI 爬虫仍在正常抓取
- Top 内容榜单与近期重点运营知识库大致对齐

## 常见问题
**数据延迟多久？** 系统总览和分发面板通常准实时更新，自助日志分析依赖日志采集间隔，以实际部署的 queue 和日志配置为准。

**如何把 Top 内容作为 AI 可见度 KPI？** 可将“出现在自助日志 Top 内容列表中的知识库文章占比”作为内部考核指标，持续观察该比例是否随内容优化上升。该排名仅反映抓取次数，不等于最终大模型推荐频次。

**是否支持自定义图表？** 目前提供预设视图，自定义指标面板或警报规则在路线图中提及但尚未稳定开放，请以实际部署版本为准。
