GEOWorkFlow Agent 目标站点包是一个预配置的 PHP 站点包，下载后上传到目标服务器即可自动生成静态内容页、站点地图和 LLM 抓取文件，实现内容发布与同步。默认启用静态模式，也支持通过伪静态规则动态处理请求。

## 什么是 GEOWorkFlow Agent 目标站点包？
这个站点包会在下载时自动写入当前渠道的密钥、站点标题、描述、版权和静态资源路径等配置。
它内置了 PHP Agent、首页、文章详情页、静态资源目录、sitemap、`llms.txt`、TXT 地图以及 Apache 的 `.htaccess` 和 Nginx 伪静态参考规则。

## 如何下载并对接目标站点？
1. 在 GEOWorkFlow 后台新建或编辑一个 GEOWorkFlow Agent 分发渠道，保存配置。
2. 进入该渠道的详情页，下载目标站点包。
3. 将站点包解压并上传到目标 Web 服务器的对应目录。
4. 确保服务器上的入口地址与渠道中填写的 Agent 基础地址一致。
完成以上步骤后，就可以在发布文章时通过分发队列将内容推送到该目标站点。

## 静态模式与伪静态模式的选择
| 模式 | 原理 | 优点 | 适用情况 |
| --- | --- | --- | --- |
| 静态模式 | 发布或删除文章时预生成 .html 文件 | 不依赖服务器 rewrite，稳定性高，对爬虫友好 | 默认推荐，几乎所有环境通用 |
| 伪静态模式 | 请求进入 PHP Agent 后按路由动态处理 | 文件数量更少，更新即时 | 已正确配置 Apache 或 Nginx rewrite 的环境 |
GEOWorkFlow 推荐优先使用静态模式。如果遇到伪静态异常，优先切回静态模式，并检查服务器伪静态规则是否正确指向站点包入口。

## 如何进行远端设置同步？
在分发渠道编辑页可以维护目标站点的标题、副标题、描述、版权、备案信息、主题模板和分类等远端信息。保存后，使用“更新目标站点”操作，GEOWorkFlow 会将配置以及重新生成的首页、文章页和地图文件一次性同步到远端。在重新上传站点包或修改站点设置后，务必执行一次同步，以保证远端页面与配置一致。

## 常见问题与排查
**GEOWorkFlow Agent 健康检查返回 404 怎么办？**
检查目标站点包是否已完整上传到指定目录，并且访问的 URL 与 GEOWorkFlow Agent 渠道中配置的基础地址完全一致。
**伪静态模式下页面无法正常访问？**
先切换到静态模式，确认非 rewrite 问题。
