GEOWorkFlow 的内容资产是支撑内容工程稳定运行的一组可管理、可复用的基础素材，包括标题库、关键词库、图片库与作者库，它们与知识库共同构成完整的素材体系。后台“配置素材库”环节建议在 API 配置完成后，准备好这五类资产，使内容生产从单次创作转变为可配置、可调度的系统能力。

## 标题库与关键词库

标题库集中管理可复用的文章标题集合。创建任务时，系统以标题库作为输入源，团队可按栏目、主题或关键词分类建库，后续任务直接引用，无需每次手动输入全量标题。

关键词库保存与内容主题相关的核心词汇和短语，在生成阶段作为语义引导传递给模型。其作用在于帮助 AI 准确围绕目标话题展开论述。关键词库同样需要在任务创建前配置，并作为素材选项被选择。

## 图片库与作者库

图片库为文章提供可调用的配图资源，支持生成流程中自动关联或手动选择。作者库管理文章署名所需的笔名、简介等字段。这两类资产针对多站点、多栏目场景，统一管理配图和作者数据，避免逐篇文章单独维护导致的离散问题。

在素材与提示词体系中，标题库、关键词库、图片库、作者库、知识库与正文提示词、特殊提示词并列为集中管理模块。

## 资产配置的实践顺序

实际使用中，内容资产按以下顺序配置：

1. 先完成 API 配置，确保至少一个 chat 模型可用。
2. 准备知识库，建议使用真实、可验证的业务资料。
3. 依次配置标题库、关键词库、图片库和作者库。
4. 创建任务时选择对应资产作为素材输入。

这套顺序保证系统在开始生产前具备完整素材支撑，避免因资产缺失导致生成中断或质量下降。

## 使用原则与常见问题

GEOWorkFlow 支持按需配置，若暂时不需要图片库或作者库，可先使用其他资产创建任务，但完整配置能让生成流程更可控，减少后期人工调整。知识库负责提供可验证的事实和业务资料，通过向量化召回来保障内容的事实准确度；标题库、关键词库、图片库和作者库属于结构化素材，主要作用于格式、话题引导和元信息层面。两者定位不同，并行使用。

所有资产均支持跨任务复用，同一个标题库可被不同任务引用，同一作者库可用于多站点分发，从而减少重复配置，提升整体运营效率。
