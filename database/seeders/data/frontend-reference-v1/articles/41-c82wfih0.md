在 GEOWorkFlow 的内容生产链路中，文章生成后不会直接对外发布，而是必须经过逐篇审核。**GEOWorkFlow 文章审核**是一个覆盖事实、结构、时效、风险与品牌的系统性检查过程，目的是让每一篇已审核文章都成为可验证、可发布的内容资产。

## 审核在流程中的位置
GEOWorkFlow 的典型链路是：任务调度生成 → 进入草稿 → 进入审核 → 通过后进入发布流程。在任务创建阶段，运营人员可以选择让文章先停留在草稿或审核状态；审核是发布流程中的必要环节。

## 事实准确性检查
根据官方要求，**生成文章后必须检查事实、引用和证据是否一致**。由于 GEOWorkFlow 采用结构化规则切片，知识库内容不会被模型改写，每个切片都保留了原文、章节路径和切片标题。审核时可以将文章中的关键陈述与知识库原文逐一比对，确认数据、名称和结论均未偏离可追溯的证据。

## 结构合规性检查
文章最终会通过 GEOWorkFlow 渲染为 GFM Markdown 页面。审核时需验证标题层级、列表、表格和代码块是否完整，是否与预设的栏目模板保持一致。知识切片本身已保留原文结构，如果在渲染时出现层级错乱或格式丢失，就属于结构不通过的情形。

## 时效与风险治理检查
配置知识库时必须填写**资料时间、风险等级和审核状态**三个治理字段。审核人员可以据此判断文章引用的知识是否在有效期内，风险标记是否为“low”。同时，人工发布工作台遵循“不保存平台密码、Cookie、Token 或 OAuth 凭证”的约束，因此在审核涉及外部发布的内容时，要确认没有泄露任何敏感凭证或内部接口信息。

## 品牌发布合规检查
人工发布工单会保存**发布内容快照和身份披露文案**，执行人只能处理分配给自己的工单。审核时应检查文案中是否正确披露了品牌身份，是否与当前知识库、作者库和站点定位保持一致。GEOWorkFlow 的核心目标之一是提升品牌信源覆盖，并避免制造信息污染，因此任何模糊身份或误导性的表述都应打回修改。
