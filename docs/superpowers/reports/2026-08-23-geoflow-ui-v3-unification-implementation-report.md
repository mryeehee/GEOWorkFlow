## 3. 实施期间发现并修复的问题

1. Docker 内 `artisan serve` 的热重载子进程会丢失容器数据库环境变量。启动命令增加 `--no-reload`，并增加基础设施回归测试。
2. AI 任务草稿缺少旧 PostgreSQL 表要求的标题库、内容提示词和模型外键。任务创建现在自动选择旧系统可用配置；缺少配置时返回可操作的引导错误。
3. Agent 结构化参数遗漏任务文章数量和发布间隔。两个 Agent Schema、规则解析器和协议测试均已补齐。
4. 极端发布间隔可能发生整数溢出。时间换算增加饱和保护，编译器继续执行范围校验。
5. 前端锁文件包含高危依赖告警。锁文件已更新，当前 `npm audit` 为 0。
6. 正式安装入口仍可通过旧开关导入演示数据。两个正式入口已移除该行为，旧变量仅保留兼容说明。
7. 本地开发文档仍描述应用与 Reverb 分离端口。文档已统一为 18080 同源网关。
8. UI V3 临时评审文件被跟踪在 `storage/app`。这些文件已从集成结果移除，避免改变旧文件存储对账结果。
9. AI 单次多站分发会覆盖任务已保存的默认渠道。执行器现按本次审批矩阵精确入队并保留任务配置，`distribution.publish` 能力版本升级到 `1.4.0`，旧审批自动失效。
10. 托管站点需要走任务托管分发流程。计划编译器现会在生成审批前拒绝托管站点目标，并返回明确的操作引导。
11. 页面加载后发生 Runtime 关闭、模型不可用或会话过期时，错误会继续进入居中引导弹窗；中文输入法同时补充 `keyCode 229` 兼容保护。
12. 全量测试中的知识文件上传用例会写入真实旧文件目录。测试现同时隔离本地与公共存储，复跑后文件数和总字节保持基线值。

## 7. 回退方式

### 快速运行时回退

1. 保持 `GEOFLOW_AI_WORKSPACE_RUNTIME_ENABLED=false`。
2. 如需回退界面，将 `GEOFLOW_ADMIN_UI_V3_ENABLED=false` 并重启应用容器。

### 代码回退

1. 停止应用、队列、调度器和 Reverb。
2. 切换到 `codex/archive-admin-ui-wip-20260823`。
3. 使用旧 Compose 配置重新启动。
4. 默认保留新增 AI 会话和审计数据。
