## 2. 问题与修复结果

| 优先级 | 问题 | 影响 | 修复结果 |
| --- | --- | --- | --- |
| P1 | 在线激活存在进程中断窗口 | 第一次事务已把站点切为 `online`，进程在最终激活前退出时，公开页面可能提前返回 200 | 激活期间写入一次性内部令牌；公众统一得到 503，只有携带匹配令牌的技术探针可以访问；激活完成后删除令牌 |
| P1 | `auto_approved` 文章在托管链路中被拒绝 | 自动审核文章可以进入通用分发，却无法创建托管分配请求、发布或公开展示 | 在 `ArticleWorkflow` 统一可发布审核状态，分配、发布、恢复、索引计数和公开查询共同使用 `approved + auto_approved` |
| P1 | 待分配请求不会跟随任务改绑 | 容量不足期间把任务从站点 A 改绑到站点 B，旧请求仍指向 A，随后会被取消且无法自动恢复 | 请求创建改为固定锁序事务；未生成归属的请求会复核最新任务契约并更新 profile 血缘，然后继续在新站点分配 |
| P1 | 开放索引缺少联系方式与运行观察证据 | 配置完整但没有公开联系入口的站点可通过预检；刚上线或近期出现 5xx 的站点可立即开放索引 | 新增公开联系邮箱，联系方式检查接受有效邮箱或有效白名单表单；开放索引前默认观察 30 分钟，窗口内出现 5xx 时拒绝索引 |
| P2 | 托管写请求只依赖路由中间件授权 | 当前路由安全，但 Form Request 缺少独立的超级管理员防线 | 所有托管创建、编辑、状态、索引、归档和文章指派请求均复核超级管理员权限及渠道类型 |
| P2 | 异常 `hosted_site` 渠道缺少 profile 时详情页可能报错 | 手工数据修复或历史脏数据可能触发空关系访问 | 控制器在进入详情与生命周期动作前验证 profile 存在，异常资源返回 404 |
| P2 | 测试套件受本机站点名和后台路径影响 | 主工作区使用自定义 `SITE_NAME` 或 `ADMIN_BASE_PATH` 时，同一代码会出现环境相关失败 | PHPUnit 配置与测试基类在应用启动前固定测试默认值，隔离 `.env` 与已导出的进程变量 |

## 3. 关键实现说明

### 3.1 激活故障安全

激活仍采用维护态预检、在线探针、最终激活三段流程。在线探针阶段新增以下约束：

1. 渠道保持 `paused`，profile 临时进入 `online + noindex`。
2. 渠道配置保存一次性 `hosted_site_activation_token`。
3. 托管公开面检测到令牌时，只接受 `X-GEOFlow-Hosted-Activation` 的精确匹配值。
4. 普通请求、错误令牌和进程中断后的请求均返回 `503 + noindex`。
5. 在线检查完成并提交 `active` 后清除令牌。

这项调整覆盖了探针失败和 PHP/Worker 在两次事务之间退出的场景。

### 3.2 审核状态契约

新增统一的 `ArticleWorkflow::PUBLISHABLE_REVIEW_STATUSES` 和判断方法。托管分配请求、分配器、发布器、显式恢复、索引文章计数和站点文章查询不再各自维护审核状态字面量。

### 3.3 分配请求改绑

请求服务按 `channel → profile → allocation request → article` 顺序加锁，并在事务中再次检查：

- 文章仍属于当前任务；
- 任务仍为 `distribution_only`；
- 任务只绑定一个托管渠道；
- 文章状态和审核状态仍可发布；
- profile 仍属于目标渠道。

已有归属保持稳定，只有尚未生成归属的请求可以更新任务与 profile 血缘。

### 3.4 索引质量门禁

新增配置：

```dotenv
GEOFLOW_HOSTED_SITE_INDEX_OBSERVATION_MINUTES=30
```

索引状态切换为 `index` 时继续执行在线预检，并增加：

- 站点已完成本次激活后的观察窗口；
- 最近观察窗口内没有该 profile 的 5xx 访问记录；
- 公开联系邮箱有效，或至少存在一个有效白名单联系表单。

每次重新激活都会重新记录 `activated_at`，从而重新开始观察窗口。公开联系邮箱显示在托管关于页，创建与编辑页已增加对应字段。

## 4. 新增回归覆盖

- 激活中断令牌：公众 503、错误令牌 503、正确内部令牌 200。
- 技术探针携带一次性激活令牌。
- `auto_approved` 文章完成请求、分配、发布和公开展示。
- 未生成归属的 pending 请求在任务改绑后迁移到新 profile。
- 预检拒绝缺少公开联系方式的站点。
- 索引拒绝未完成观察窗口和近期存在 5xx 的站点。
- 异常托管渠道缺少 profile 时返回 404。
- Form Request 与路由共同约束超级管理员和托管渠道类型。
- 自定义站点名和后台路径环境下，默认品牌与 Host 边界测试保持稳定。
