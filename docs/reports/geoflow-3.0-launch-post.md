# GEOFlow 3.0 发布长推文参考

感谢这段时间参与 GEOFlow 测试、提问题、给建议的每一位朋友。过去几周，我重新整理了后台、AI 工作台、文章质检、分发和升级链路，GEOFlow 3.0 现在有了一套更完整的产品形态

我想把它定义为：全球首个面向企业官网的开源 GEO 智能运营系统

官网是 GEOFlow 的主要场景。企业可以把产品资料、案例、FAQ、行业知识和品牌规则沉淀进知识库，再把内容生成、AI 质检、人工审核、官网发布、渠道分发和数据分析接在一起。它也能用于官网 GEO 子频道、独立信源站、内部内容管理后台和多站点运营

这次 3.0，我重点补了几块官网 GEO 长期运营时一定会遇到的能力

后台界面全面升级为 Admin UI V3，主要页面使用统一的侧栏、顶栏、导航、表单和交互规范，增加最近访问、侧栏宽度调节、移动端布局、键盘操作和无障碍状态。后台同时支持中文、英文、日语、西班牙语、俄语和葡萄牙语（巴西）

AI 工作台调整为图文帮助助手。系统内置覆盖 15 个后台主题的知识库、24 张脱敏截图和 72 条固定评测，管理员可以直接问某个功能在哪里、一条流程怎么走、一个状态代表什么。回答通过流式方式返回，站内入口由服务端按当前权限生成

文章 AI 质检已经接进发布门禁。每篇文章会结合任务知识、版本化广告规则和发布语境检查知识一致性、数据与引文、广告风险和内容完整性，保留分项评分、原文位置、证据、法规依据、修改建议和历史记录。低分、阻断、异常和过期结果会留在草稿阶段，人工放行也有独立授权和审计记录

多站点能力增加了托管渠道站点，支持子域名分配、文章分配、发布配额、失败冷却、技术预检、缓存失效和状态对账。现有 GEOFlow Agent、WordPress REST、通用 HTTP API 和目标站点包继续保留，官网内容可以进入不同的站点与渠道

人工发布工作台接入 Chrome 运营助手。它用设备配对和最小权限 Token 领取工单、校验账号、填充草稿并回传执行凭证，最终发布仍由运营人员确认。后台也可以安装为 PWA，作为独立工作台使用

内容运营里的长任务也补齐了。标题库支持最高 10 万条的分批 AI 生成、恢复、取消、失败重试和去重；任务删除进入保留 90 天审计信息的回收站；文章可以批量导出 Markdown ZIP

工程侧增加了更清楚的边界：API v1 和 GEOFlow CLI 覆盖目录、任务、执行记录、素材、文章和浏览器运营协议；独立 GEOFlow Updater 负责网站更新、完整备份、环境验收和恢复点回滚，高风险操作需要管理员密码与 6 位验证器授权码

我对官网 GEO 的判断很直接。持续获得 AI 引用，需要真实知识、稳定内容、清楚结构和长期运营。模型负责提高效率，知识库、质量门禁、发布流程、站点工程和数据反馈决定这套系统能不能持续运行

GEOFlow 3.0 已经把这些能力放进同一个开源项目里。欢迎试用，也欢迎继续把真实问题提给我
