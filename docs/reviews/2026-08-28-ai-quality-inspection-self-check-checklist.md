# AI 质检升级自检清单

- 自检日期：2026-08-28
- 对照方案：[AI 质检工作流升级方案](../superpowers/plans/2026-08-27-ai-quality-inspection-workflow-upgrade-plan.md)
- 自检结论：AI 质检范围与整库全量测试均通过

## 1. 任务配置

- [x] 新建任务时 AI 质检默认关闭
- [x] 打开开关后显示质检方案、模型、知识库、自动放行分数和人工放行最低分
- [x] 默认自动放行分数为 85 分，人工放行最低分为 70 分
- [x] 质检方案仅允许选择 `quality_inspection` 类型提示词
- [x] 支持指定模型和智能模型选择两种模式
- [x] 支持任务创建、编辑、详情展示与 API 配置校验
- [x] 修复打开 AI 质检后页面滚动到空白区域的问题
- [x] 任务保存后固化文章级质检策略快照，避免后续配置变更改写历史判定

## 2. AI 配置器与默认提示词

- [x] AI 配置器包含 AI 质检方案类型、创建、编辑、删除和复制入口
- [x] 内置一套 RTF 结构化默认提示词，覆盖角色、任务、流程、评分维度、证据要求和 JSON 输出协议
- [x] 默认提示词要求结合知识库、广告合规规则、数据与引用进行核查
- [x] 默认提示词由迁移脚本幂等同步，可在新安装和升级场景稳定生成
- [x] 系统默认方案提供只读保护，复制后可形成自定义版本
- [x] 模板变量采用白名单渲染，文章内容与知识证据使用明确边界标签隔离
- [x] 模型输出经过结构校验，错误字段、越界分数、伪造定位和不完整结果会触发失败或候选模型切换

## 3. 质检工作流

- [x] 任务启用后，每篇新生成文章都会创建独立质检记录
- [x] 文章生成完成后进入异步 AI 质检环节，原有后续流程在质检放行后继续
- [x] 长文章按结构分段质检，保留段落、字符位置和原文快照
- [x] 已完成分段可在重试时复用，减少重复调用
- [x] 队列重试、终态失败和计划任务对账均可收敛父记录状态
- [x] 记录变为过期或取消时，运行中的分段同步进入终态
- [x] 质检服务异常、知识库缺失或模型全部失败时采用关闭放行的安全策略
- [x] 已人工驳回文章不会被后到达的异步通过结果重新放行

## 4. 评分与结论

- [x] AI 返回维度判断与问题证据，最终分数由系统固定规则计算
- [x] 评分覆盖知识一致性、数据可追溯性、广告合规和内容完整性
- [x] 严重广告法风险、知识库严重冲突和关键数据不符可触发确定性拦截
- [x] 85 分及以上且无阻断问题时自动通过
- [x] 70 至 84 分进入人工审核，可在满足条件时记录人工放行
- [x] 70 分以下或存在阻断问题时保持草稿并标记 AI 质检不通过
- [x] 普通风险审核理由不能隐式绕过 AI 质检门禁
- [x] 人工放行记录包含操作人、时间和理由

## 5. 发布与分发门禁

- [x] 后台文章发布入口接入 AI 质检门禁
- [x] API 文章发布与内容更新入口接入 AI 质检门禁
- [x] 工作流状态迁移、后台任务、CLI、自动分发、人工发布和浏览器发布入口接入同一门禁
- [x] 待检、运行中、失败、过期、取消和不通过结果均不能进入新增发布或分发流程
- [x] 已发布文章复检不通过时保持当前线上状态
- [x] 已发布风险文章会阻止后续内容更新和新增分发，直至修订并重新质检通过
- [x] 配置或证据失效后，尚未发布文章回到待检草稿状态

## 6. 失效与可追溯性

- [x] 文章正文、标题、任务策略、提示词、模型、候选模型集合、知识库、广告规则和分发策略参与指纹计算
- [x] 相关输入发生变化时，旧结果标为过期并创建新的质检要求
- [x] 提示词或模型删除后仍可通过快照查看历史结论
- [x] 智能模型模式记录候选顺序、实际成功模型、逐次尝试结果和累计用量
- [x] 模型调用记录过滤 API 密钥、请求头和异常堆栈等敏感信息
- [x] PostgreSQL 与 SQLite 的 JSON 查询表达式分别适配
- [x] 对账任务能够修复超时运行记录和缺失质检记录

## 7. 文章列表与详情

- [x] 文章列表新增 AI 质检字段、状态、分数和筛选条件
- [x] AI 质检不通过、待人工审核、处理中、失败和过期状态使用不同颜色
- [x] 已发布风险文章显示独立风险提示
- [x] 文章详情展示当前结论、总分、维度分、问题、理由、建议、引用和完成时间
- [x] 每项问题展示对应字段、段落、原文摘录和定位按钮
- [x] 重复原文摘录按出现序号和 Unicode 字符偏移定位
- [x] 历史记录可展开查看当时的结论、问题和原文快照
- [x] 页面文案已补齐中文、英文和本轮新增的葡萄牙语 AI 质检键

## 8. 单篇手动 AI 质检

- [x] 没有质检记录的文章编辑页显示“一键 AI 质检”按钮
- [x] 有历史记录时支持再次发起质检，并保留全部旧结论和原文快照
- [x] 点击后先保存当前编辑表单，再使用保存后的内容创建质检快照
- [x] 单篇质检只更新文章级策略快照，不修改所属任务的 AI 质检开关
- [x] 每次手动质检读取当前任务知识库、质检方案、可用模型和评分阈值
- [x] 专用质检模型停用时可回退到任务正文模型或系统可用聊天模型
- [x] 缺少知识库、提示词或可用模型时显示安全提示，文章和历史记录保持原状
- [x] 已发布文章内容未变化时保持已发布状态并在后台排队复检
- [x] 私有或已发布文章内容发生变化时先进入待审核草稿，质检通过后恢复用户请求的目标状态
- [x] 手动请求记录后台管理员、API 令牌、触发来源和请求时间
- [x] 后台与 API 分别配置频率限制，API 同时限制令牌、单篇文章和来源地址
- [x] 新鲜运行记录不会被第二个工作进程重复领取，中断记录可由队列重投和对账任务恢复
